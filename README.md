# Apex

Apex is the hardware and software for a fast line-following robot built for the MEB robotics competition.

## Commit Messages

Follow [Conventional Commits](https://www.conventionalcommits.org/): `type: short imperative description`.

Common types: `feat`, `fix`, `docs`, `chore`, `style`.

Examples:
- `feat: add motor driver circuit to schematic`
- `fix: correct IMU SPI chip select pin`
- `docs: update README with build notes`
